## Start here

Use these docs when you are ready to set up, evaluate, or operate a Caimeo project. Start with the project that matches what you are trying to do, then follow the shortest path for your role.

If you are still deciding which product matters first, start with Brainstack. It has the most concrete setup path today and gives the rest of the suite durable memory, context, and lessons.

## Choose a project

- **[Brainstack](/docs/brainstack/)**: shared memory, skills, local capabilities, Mac setup, proposal curation, Telegram control, and private machines. See the [Brainstack product page](/brainstack/) first if you want the short pitch.
- **[Forseti](/docs/forseti/)**: typed action requests, policy decisions, human approvals, execution release, and audit evidence. See the [Forseti product page](/forseti/) for the pilot offer.
- **[Tyche](/docs/tyche/)**: deterministic scenario packs, comparison runs, scoring, and replay bundles for agent behavior. See the [Tyche product page](/tyche/) for the replay-bundle story.
- **[Valhalla](/docs/valhalla/)**: governed multi-agent delivery rooms with roles, budgets, audits, and stop criteria.

These pages are meant to get you to the next decision or command quickly. Deeper reference material can come later as each product surface grows.
